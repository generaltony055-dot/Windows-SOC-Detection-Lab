# DNS Query Monitoring — MITRE ATT&CK Mapping

## Detection
DNS Query Monitoring

## Log Source
Sysmon Event ID 22 — DNS Query

## SIEM
Splunk Enterprise

## Detection Logic
The detection monitors DNS queries and identifies the
process responsible for each query and the requested domain.

## Observed Activity
The lab captured DNS queries generated by:

TrueViewManager.exe

Examples included:
- upd.appsalt.com
- ipinfo.io
- cloudflare-dns.com

## Investigation
Relevant fields include:

- Image
- QueryName
- QueryStatus

## Assessment
The observed DNS queries require contextual investigation.
A DNS query alone does not establish malicious activity.

## MITRE ATT&CK
The collected evidence does not by itself establish a
specific ATT&CK technique.

T1046 — Network Service Scanning should not be assigned
because the lab evidence shows DNS queries, not network
service scanning.

## Result
Sysmon Event ID 22 successfully captured and indexed
DNS query activity in Splunk.
